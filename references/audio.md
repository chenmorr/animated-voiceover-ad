# אודיו

## אתה לא שומע

כל החלטה על אודיו מבוססת מספרים, ובעל העסק מאשר באוזן. כלים:
- `ffmpeg -i X -af silencedetect=noise=-40dB:d=0.4 -f null -` לשקטים
- `ffprobe -v error -show_entries format=duration -of csv=p=0 X` לאורך
- `ffmpeg -i X -af ebur128 -f null - 2>&1 | tail -12` לעוצמה (Integrated LUFS)
- תמלול של ה-mp4 המרונדר (`ffmpeg -i out/X.mp4 -ar 16000 -ac 1 /tmp/r.wav` ואז whisper) כדי לוודא שכל הקריינות שם עד המילה האחרונה

## ניקוי הקלטה

`npm run vo -- recording.m4a` עושה:
1. חיתוך כל שקט מעל 0.25 שנ' (פחות אוויר = קצב של מודעה)
2. נרמול ל-‎-16 LUFS
3. עותק 16kHz מונו ל-whisper
4. `words.mjs`: whisper עם `-ml 1 -sow` (מילה לכל שורה) ← `public/words.json`

### טייקים כפולים

אם בעל העסק טעה והתחיל משפט מחדש, צריך למחוק את הטייק הרע **לפני** `npm run vo`:
1. מריצים `npm run vo` פעם אחת רק כדי לראות את התמלול עם זמנים.
2. whisper לפעמים "מעלים" משפט שנאמר פעמיים. אם חשוד, חותכים את הקטע ומתמללים אותו לבד (`ffmpeg -ss A -t B`): בקטע קצר הכפילות מופיעה.
3. את נקודת החיתוך לוקחים מ-`silencedetect` על ההקלטה המקורית, לא מזמני whisper (whisper טועה בשניות שלמות ליד שקט).
4. חותכים עם `atrim` + `acrossfade=d=0.03` ומריצים `npm run vo` על הקובץ הנקי.
5. לא מחברים חצאי משפטים משני טייקים. אם יש טייק שלם של המשפט, לוקחים אותו.

## מוזיקה ואפקטים

`npm run setup` מוריד מ-Mixkit (חינם לשימוש מסחרי, בלי קרדיט):

| קובץ | מתי |
|---|---|
| `pop` | KT מסוג pop |
| `stamp` | KT מסוג stamp, חותמות |
| `whoosh` | KT מסוג slide/drop, 3 פריימים לפני כל מעבר סצנה |
| `note`, `ding` | התראת אינסטגרם/וואטסאפ |
| `dm` | הודעה מלקוח |
| `coin` | התראת תשלום |
| `cash` | כשהמונה מגיע למספר הסופי |
| `tick` | צ'יפים בכרטיס ההצעה |
| `cta` | כניסת הסיום |

רוב האפקטים מתחברים אוטומטית ב-`Ad.tsx` לפי סוג הרגע. אפקט נוסף על מילה: `EXTRA_SFX`.

מוזיקה: 3 טראקים ב-`public/music`, כל אחד גרסה. להוסיף טראק: מורידים מ-mixkit.co/free-stock-music ל-`public/music/<שם>.mp3` ומוסיפים את השם ל-`MUSICS` ב-`Root.tsx`. בוחרים מוזיקה עם אנרגיה (funk, upbeat), לא אמביינט.

לא מסנתזים אפקטים ב-ffmpeg (בעיקר "כסף"). זה נשמע מזויף. תמיד הקלטה אמיתית.
